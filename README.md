# Job Satisfaction Prediction Project 🚀

This project uses **Machine Learning** to predict job satisfaction levels based on various factors like age, industry, and education.

## Tools Used:
* **Python** (Pandas, Scikit-learn)
* **PyCharm** * **GitHub** for version control

## How it works:
The model analyzes the `ai_job_impact.csv` data to find patterns and provide predictions on how satisfied an employee might be in their role.
